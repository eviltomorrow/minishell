# 03 — 底部汇总行

**What to build:** 探测完成后，在底部状态栏显示汇总行 `12/15 可达`（可达数 / 总机器数）。机器增删改后汇总数字随之刷新；探测全部结束前不显示或显示"探测中"，结束后自动转为最终数字。

**Blocked by:** 02 — 启动探测 + 状态列全链路

**Status:** resolved

- [x] 底部显示汇总行：`可达数/总数 可达`
- [x] 探测全部完成后自动从"探测中"切换到最终汇总数字，无需按键
- [x] 机器增删改触发列表刷新时，汇总数字随之更新

## Answer

`app.rs` 状态栏左侧插入汇总 span：探测未完成（`probe.is_done()` 为假）时显示灰色 `探测中…`，完成后显示 `N/M 可达`（N 为可见机器中 OK 数，M 为当前可见机器数），全部可达时绿色。汇总随每帧重绘与 `reload_machines` 自动刷新。`cargo build --release` 与全量测试通过。
